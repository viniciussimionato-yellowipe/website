# 0006 · Análise só com consentimento e sem dados pessoais

**Estado:** aceite · 2026-10-30

## Decisão

GTM carregado só depois de aceitar análise (modo básico do Consent Mode). Eventos tipados sem dados pessoais. Atribuição da primeira visita num cookie próprio, só com consentimento. O CRM é a fonte de verdade das oportunidades.

## Consequências

- Menos dados no GA4 (quem recusa não é medido); o CRM continua a medir a origem de cada lead pelos campos escondidos.
- A plataforma de consentimento definitiva tem de respeitar este contrato.
